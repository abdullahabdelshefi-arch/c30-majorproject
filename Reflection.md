# Major Project Reflection

## Advice I would give my self
- If I could go back and give myself advice before starting this project, I would tell myself to spend more time planning the code and testing each feature as I built it. Sometimes I would add several new features before testing them, which made it harder to find bugs later. Better planning would have helped me organize my code more efficiently and avoid some of the debugging problems I faced during development. Testing more often would have saved time and made fixing errors much easier.

## Was eveything in needs to have complete
- Yes, everything in the needs-to-have list was completed successfully. All of the required game features were added and working by the end of the project. In addition to the required features, I was also able to include some of my nice-to-have ideas to improve the game and add more of a "wow factor."

## Hardest part
- The hardest part of this project was creating the AI system for the enemies. I wanted the enemies to do more than simply follow the player in a straight line. In hard mode, different enemies use different strategies, such as predicting where the player will move, attacking from the side, or trying to cut off escape routes. Making these behaviors work properly required a lot of testing, debugging, and adjusting values. It took several attempts before the enemy movement felt challenging while still being fair for the player.
